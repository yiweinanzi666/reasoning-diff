## 2. 标签与测量

1. `R_task` 是原始输入前提到任务节点的完整祖先集合；独立于模型输出建立。
2. `R_behavior` 是指定模型、解码参数、随机流和允许扰动集合下的经验响应。明确保存扰动范围、观测次数和不确定性。
3. 对齐依赖变量/表达式/版本/作用域的事件身份，不依赖数值相似度。消失、合并、策略改变归入结构变化；缺失不能写成 0。
4. `S = R_behavior \\ R_task`；`M = R_task \\ R_behavior`，始终分开。有限扫描中的 M 不等于已经证明“从未读取”。
5. 分母为空用 N/A/null，报告有效事件数、支持前提数和覆盖率，不用 0 代替。
6. 噪声参照必须有明确的配对机会和共同支持集合。未注册配对规则时 corrected 量为 null；不能给一个无编辑随机变化强加具体前提身份。
7. 记录原始值、噪声参照与有符号差值，不把负差值截成 0，不把差值称作已经识别的因果真值。
8. TO 全链与干净区域分开；CSP 只在匹配事件上计算，同时报告覆盖率、脏事件变化率、结构变化和失败数。

## 3. 数据划分与拟合边界

- 同基础题的数值变体、改名、no-op、连续编辑、donor 配对及不同模型轨迹保持共组。
- 探针训练、开发选择、方向拟合、校准、无标签迁移配对和最终测试分别记录。具体比例在生成实验数据前注册。
- 有测试专用使用约束的数据集固定为评测集，不能参与拟合和校准。
- 标准化、特征选择、阈值、层选择、方向/维数、Procrustes 和统计预测器都视为拟合步骤，不能读取测试标签。
- 保形单位是完整轨迹或完整编辑序列。经验行为标签下的覆盖对象仅是相应扫描协议下的标签，不是任意未观测扰动。

## 4. 干预必须同时成立的条件

- 主干预在目标步骤第一个 token 之前；保留精确前缀、层内 hook 位置和 KV 更新范围。跨界 token 不得泄漏目标内容。
- donor 来自事件可对齐的任务对；每个数值条件独立提取 donor 表征，来源与数值不能混淆。
- 等值不同来源用于解耦，非等值配置用于评价来源跟随。目标和非目标响应由高层任务关系预先指定。
- C-rand 为同层同位置同维随机正交子空间；C-layer 为开发集证实依赖信息较弱的层。记录实际扰动范数并匹配，而不只共用一个系数。
- 交换、消融、救援均记录基线、两类对照、目标/非目标、任务正确性、无效和截断输出。所有失败保留在分母与明细中。
- 救援是机制诊断；在同一点加回原分量可能只是恒等重建，需错误来源/随机分量对照，不能单凭恢复作强因果宣称。

## 5. P1–P3 与 Week-8 Decision Rule

第 8 周是原框架中的证据审查节点，不是自动在日历上触发的任务。本次不创建自动化、不运行实验、不修改论文结论。

| 检验 | 预先固定的比较 | 必须保留的限制 |
|---|---|---|
| P1 | 留出题目上比较链长+op 基线和加入虚假依赖的预测器；报告 AUC 及增量、问题级区间 | 控制变量和数据划分预注册；相关性不证明因果 |
| P2 | 同基础题原版/no-op 配对；注入位置与相关度分层；报告 Δrho、Δacc 和污染事件位置 | 注入改变前提数，必须明确共同分母和新增前提统计 |
| P3 | 选择性消融相对于 C-rand/C-layer 的恢复差值 | 同时报告非目标响应、无效输出和区间；负结果保留 |

决策规则：

1. 标签/对齐或噪声协议尚未可靠时，状态为 **测量待解决**，不判定科学主张失败或成功。
2. 噪声扣除后证据不足时，C3 保留负结果或描述性统计，不自动触发 P2/P3 的大规模追加运行；先检查功效和测量误差。
3. P1–P3 达到预注册标准时，C3 成为首要主张；C1 降为方法铺垫；C4 全部放附录；跨模型迁移作为第二个重点研究问题，只有实测支持时才形成肯定结论。
4. P1/P2 支持但 P3 不支持时，可保留 C3 预测/关联结论。**不能据此断言虚假依赖一定只是后果**，也可能是方向定位、干预有效性或统计功效不足。
5. C2 被两类对照追平时，报告未观察到选择性控制；保留 C1/C3 的有效证据，不以“输出变了”替代机制结论。
6. 迁移不成立或因维度不兼容不适用时，分别报告；不能把适配后性能命名为零适配直接迁移。
7. C3 不成立时不临时强凑四项主张。依可复查证据收缩主线；所有分流连同样本数、区间及失败记录一起保存。
