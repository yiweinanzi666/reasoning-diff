# Reasoning Diff

## What This Is
面向论文框架的科学实验项目。以 C3 虚假依赖及跨模型探针迁移为优先研究问题，包含 C1 前瞻可解码性、C2 来源交换/消融/救援与附录 C4 局部重算；计划覆盖 T1–T4 数据与实验入口。
本次仅交付 GSD 项目初始化：项目定义、需求、研究、路线图和交接状态。用户同事后续实现代码；真实模型、数据下载和 GPU 实验等待服务器。

## Core Value
每一条依赖标签、干预效应和实验结论都能追溯到原始事件、独立划分、对应对照与可复查的统计记录。

## Requirements
### Validated
尚无已实现功能或科学结果。技术预研不等于交付代码，也不等于科学假说成立。
### Active
- [ ] 完整数据、轨迹、事件、行为标签与噪声参照链路。
- [ ] 冻结模型隐状态、探针、文本基线、轨迹校准与迁移。
- [ ] 前瞻干预和同批次 C-rand / C-layer，P1–P3 与 Week-8 决策。
- [ ] 无门控重算与离线评分、成本计量、错误保留。
- [ ] T2/T3 全套接入与实验代码（用户已确认），以及 T4 边界数据。
- [ ] 同事后续实现并验证代码；服务器就绪后另行执行实验。
### Out of Scope
- 服务器部署和真实 GPU 实验：等待用户实验机器。
- RL、生产门控、验证器运行时回退：论文当前范围排除。
- 论文投稿、对外发布和杜撰结果：未授权且不属于代码交付。
- 本次实现代码、测试或部署环境：用户最新明确要求只初始化 GSD 项目。

## Context
原始材料：`Reasoning-Diff-修订方案-v3 (1).md`，保持原文件不变。
用户提供的最小实验建议作为优先研究方向：C3 + 跨模型迁移，C1 为工具，C4 全部放附录；材料内提问不是用户操作指令。
用户先确认后续完整范围包含 T2/T3，随后明确本次只完成 gsd-new-project，代码由同事编写。
Gate 0–2 无注册阈值，用户确认保留待预注册，输出测量值但不自动宣布通过。
文档有未经证明的推论：步前可解码不能单独证明已经决定；P3 失败不能推出虚假依赖只是后果；有限单点扰动不证明任意联合编辑 soundness。

## Constraints
- Windows/Python 本机；可迁移 Linux GPU。代码验证与科学验证独立记录。
- 同基础题全变体同划分，训练/开发/方向拟合/校准/迁移配对/测试分离。
- 有限扰动未变化不等于绝对无依赖；未对齐、结构变化和失败保留。
- 数据来源真实标记；自建算术 DAG 不冒充官方 iGSM。
- 干预发生在目标事件首 token 之前；token 跨界不得泄漏目标内容。
